# 🚀 FastCin — Замена `std::cin` для ЛЕГЕНД

## Что это?

**FastCin** — ультрабыстрая header-only замена `std::cin` из `<iostream>` для C++.

Проект создан специально для спортивного программирования, контестов и задач, где стандартный C++ I/O становится узким местом.

## Производительность

Замер на чтение **1 000 000 32-битных целых чисел** на Linux с `g++ -O3`:

```text
std::cin (по умолчанию):    ~1200 мс  (TLE 😢)
std::cin + отключённый sync: ~800 мс  (Всё ещё медленно)
FastCin:                       ~50 мс  (AC 🏆)
```

> **Ускорение: ~24×!** 🔥

### За счёт чего достигается такая скорость?

* **Прямой `fread()`** — чтение данных большими блоками вместо тяжёлых операций через `streambuf`.
* **Cache-friendly буфер** — отдельный буфер в куче, по умолчанию 64 КБ.
* **`std::from_chars`** — быстрый парсинг чисел без выделения памяти и зависимости от локали.
* **Inlined ASCII whitespace check** — ручной пропуск пробельных символов без тяжёлых функций C locale.

## Исправленные баги и edge cases

### 🔴 Баг #1: Потерянный знак при ошибочном вводе

**Проблема:** Если при чтении `+` или `-` после знака не было цифр, знак поглощался и мог ломать последующие операции чтения.

**Исправление:** Добавлена точка отката `sign_start_pos`. Если после знака нет цифр, позиция в буфере автоматически восстанавливается.

### 🔴 Баг #2: Некорректная обработка `\r\n`

**Проблема:** `getline` мог оставлять `\n` после чтения строк с Windows-концами строк.

**Исправление:** Добавлена корректная кроссплатформенная обработка:

* `\r\n` — Windows
* `\n` — Linux/macOS
* `\r` — классический Mac OS

## Использование

### 1. Базовый ввод — почти как обычный `std::cin`

```cpp
#include "FastCin.hpp"

int main() {
    int n;
    std::string s;
    double x;

    cin >> n >> s >> x;
}
```

### 2. Чтение строк целиком

```cpp
std::string line;

// Вариант 1: напрямую через метод
cin.getline(line);

// Вариант 2: через proxy-обёртку
cin >> in::line(line);
```

### 3. Чтение до конца файла (EOF)

```cpp
while (cin.has_next()) {
    int val;
    cin >> val;

    // Обработка val
}
```

### 4. Чтение из файла

```cpp
FILE* f = std::fopen("input.txt", "rb");

FastCin file_cin(f, 1 << 17); // Буфер 128 КБ

int n;
file_cin >> n;

std::fclose(f);
```

## Компиляция

Требуется **C++20** или новее.

FastCin использует возможности вроде `<concepts>` и `<charconv>`.

### GCC / Clang

```bash
g++ -O3 -std=c++20 main.cpp -o app
```

### C++23

```bash
g++ -O3 -std=c++23 main.cpp -o app
```

## API Reference

| Метод / Оператор   | Описание                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------- |
| `cin >> x`         | Читает `int`, `long long`, `float`, `double`, `std::string` и другие поддерживаемые типы |
| `cin.getline(str)` | Читает всю строку до `\n`, `\r\n` или `\r`                                               |
| `cin.has_next()`   | Возвращает `true`, если до EOF остались непробельные символы                             |
| `cin.is_eof()`     | Возвращает `true`, если достигнут конец потока                                           |
| `cin.reset(FILE*)` | Переназначает объект на другой поток, например `stdin` или файл                          |
